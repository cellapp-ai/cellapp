# 控制台前端基础验收

变更：`add-console-frontend-foundation`。日期：2026-09-29。

## 本期结果

- 新增 `docs/standards/README.md`、`frontend.md`、`frontend-code.md`、`design.md`，全部明确适用于前端，并提供独立于服务端、CLI 的规范入口。
- 新增私有 npm workspace `apps/console`，使用 React 18、TypeScript strict、Vite、Tailwind、本地字体及 Cellapp 品牌资源。
- 提供单页基础框架、真实页内导航、响应式菜单、键盘焦点、减少动态效果及无脚本说明；界面不连接管理 API，不展示模拟业务结果。

- 官方 npm 源安装及根 `npm ci` 干净安装复现，安装审计报告无已知漏洞。
