## 阅读与维护

开始前端任务时先阅读工程规范，再阅读受影响领域的全文。根 [README](../../README.md) 提供运行入口，OpenSpec 记录具体变更的需求、设计与任务；这里维护长期适用的前端约定。

- **现状**：可从当前实现核实的事实，不代表长期最优方案或本轮验收结果。
- **必须 / 不得**：后续前端变更必须遵守的要求，没有自动门禁的条目通过评审和人工验收检查。
- **建议 / 优先**：默认做法，有具体原因时可采用其他方案并记录取舍。
- **待改进**：尚未实现的能力或工具覆盖，不得写成已经完成。

版本以依赖清单与锁文件为准，命令以实际脚本为准。修改目录、构建、组件或设计约定时同步对应文档和入口链接；发现冲突时修正实现或规范，不以规范描述代替事实检查。仅文档改动核对路径、命令及事实即可，不增加镜像实现的形式化测试。
