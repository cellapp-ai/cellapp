# 品牌规范

适用范围：整个项目，包括控制台、服务端页面、CLI、Agent Skill、文档、图表、可访问名称和品牌资产说明；公开客户端必须提供可独立理解的相同命名规则。

## 品牌名称

- 正式显示名称使用 **Cellapp**，仅首字母 C 大写；允许按上下文使用全小写 **cellapp**。
- **不得使用 `CellApp`、`cellApp` 等内部字母大写的驼峰写法**，不把品牌拆成两个单词。
- 页面标题、导航、正文、alt、aria-label、metadata、图表标题和 HTTP User-Agent 遵守上述规则。
- 命令、包名、目录、文件名、域名和其他技术标识使用 `cellapp`，例如 `@cellapp/cli`、`cellapp.json` 和 `cellapp-server`。环境变量按既有全大写约定使用 `CELLAPP_ORIGIN`，不改变兼容契约。
- 矢量字标使用现有全小写 `cellapp` 字形，保持原比例；修改 SVG 的 title/desc 时同步文字规范，不重新拼排字形。
- 历史归档保留当时的记录；旧名称兼容、迁移说明和测试按其实际用途保留，不作为当前品牌写法。

## 维护与检查

新增或调整文案时检查可见文字和辅助技术文字；配套更新图表源文件及 HTML、应用源码及测试、README 与包描述。通过评审和全文搜索核对名称，品牌文字修正不改变命令、HTTP 字段或数据格式。

控制台 Logo、颜色、字体及布局规则见 [前端设计规范](design.md)。
