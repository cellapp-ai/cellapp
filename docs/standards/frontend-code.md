# 前端代码规范

适用范围：`apps/web` 的 TypeScript / TSX、前端样式、构建配置及前端测试。与 [前端工程规范](frontend.md) 和 [前端设计规范](design.md) 配合使用，不定义 Go、SQL 或 CLI 实现规则。

## 类型与组织

- 保持 TypeScript strict、未使用检查和 `noUncheckedIndexedAccess`。浏览器源码使用 DOM、ESM、bundler 解析和 React JSX，工具及测试使用独立配置；检查覆盖整个 `src/`，不只覆盖入口导入链。
- 组件及类型使用 PascalCase，函数、变量、hook 使用 camelCase，hook 以 `use` 开头，CSS 类使用 kebab-case。命名表达职责，注释说明原因、边界或不变量。
- 使用 `import type` 导入纯类型，保持 ESM；`@/` 指向 `src/`，变更映射时同步 TypeScript 与 Vite。浏览器源码不得导入 Node 专属模块。
- 业务数据与 props 定义明确类型；状态集合优先使用字符串联合类型。外部输入从 `unknown` 收窄，不用 `any`、非空断言或类型断言代替运行时校验。
- 新代码使用两空格缩进、单引号、分号，保持邻近代码一致；当前未引入自动格式化门禁，不宣称格式已自动强制。

## React 组件与状态

- 使用函数组件。hooks 在组件或自定义 hook 顶层调用，不放进条件、循环或事件回调；保持 hooks 与依赖检查启用。
- 渲染保持纯函数行为，不在渲染期间请求、修改 DOM 或写存储。浏览器副作用放入事件或 effect；监听器、定时器、观察器必须清理，请求应可取消。
- 状态只保存无法从 props 或已有数据推导的值；使用稳定业务标识作为列表 key，可重排列表不得使用索引。
- 围绕真实职责与复用拆分组件，不为满足行数机械拆分，也不预建 API 客户端、空页面或整套无引用 UI 原语。
- 仅在存在可测量的重复工作或引用稳定需求时使用 memo、useMemo、useCallback；避免默认添加缓存。
- 真实远程行为增加时设计 loading、empty、error、disabled 及恢复路径；静态界面不得制造虚假的加载或成功状态。

## 输入、链接与错误

- 导航使用真实 `<a href>`，操作使用 `<button>`；不得用可点击 div 代替。页内锚点必须对应实际 id，外链目的地需可信，新窗口链接应设置合适 rel。
- 路径、查询参数和外部数据先按允许值校验；新增路由同时验证直达、刷新和未知路径，不以宽泛兜底匹配替代校验。
- 不未经净化引入用户 HTML 或 `dangerouslySetInnerHTML`。浏览器环境变量和构建输出视为公开信息，不存放秘密。
- 不空 catch 或失败后显示成功。状态反馈说明可恢复步骤，不泄露凭证；复制只有完成后才提示成功，失败提供手动复制办法。
- 日期、单位、数据含义明确，使用确定的时区和格式；展示数据不能跨视图重复定义造成不一致。

## 样式与资源

- 颜色使用 `--color-*` 语义 token，间距优先使用现有尺度；CSS 与 Tailwind 引用同一值，不混用同名 HEX/HSL 变量。
- 修改样式检查实际层叠与计算结果，不持续追加全局补丁或无理由 `!important`。响应式按内容需要设计，当前主断点为 800 px。
- 栅格子项必要时设置 `min-width: 0`；长链接换行，代码/表格仅在自身容器滚动。不得隐藏主要内容来解决溢出。
- 保留 focus、减少动态效果和无脚本说明。字体从本地依赖打包，品牌 SVG 为原始来源，PNG 由对应 SVG 导出，不单独修改。
- 脚本明确输入输出、尊重超时与失败退出；构建产物由脚本生成，不手工修补。资源变更检查正式构建引用，不只看开发服务器。

## 可访问交互与检查

每页一个主要 h1，heading 层级反映内容结构，提供 main、具名 nav 和跳过正文入口。移动菜单同步 `aria-expanded`、`aria-controls` 与可访问名称，关闭后不得把焦点留在隐藏内容中；跨页导航使用 `aria-current`。

反馈通过可感知文字或 status 区域表达，不只改颜色；表单提供标签和错误关联，代码使用 pre/code，表格使用真实表头和说明，图片有恰当替代文本。触控与键盘均可操作，不能仅靠 hover 提供信息。

提交前执行前端 typecheck、lint、build，涉及行为时执行正式产物浏览器验收。测试检查可观察行为和失败恢复，不编写仅复述实现的测试。自动检查通过后仍人工检查视觉、焦点顺序与缩放；未执行检查如实记录。
