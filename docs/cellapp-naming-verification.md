## 实施结果

当前服务页面和 User-Agent 使用 Cellapp；Go module、根 npm 包及锁文件、服务二进制、默认新数据库配置、测试临时标识及存储探针使用 cellapp。四个图表文件配套改名，发布图改为授权后构建、逐文件上传，并补充已有凭证跳过授权路径。README 的浏览器验收命令与协作规范一致，包含 race 检查。

开发账号在事务锁保护下原位改名，保留 owner ID 和关联资源；新旧账号并存时明确拒绝登录。旧客户端命令、项目文件、凭证、环境变量及迁移测试仍保留。历史归档和历史验收事实不改写；历史验收文档的重跑命令使用当前默认配置。

已有数据库卷升级见 [运维说明](operations.md#命名升级)。本轮没有修改用户现有库名、角色、账号或运行中服务。

## 本轮通过

- `npm run typecheck`、`npm run build`、`go vet ./apps/server/...`。
- 指定隔离 schema 测试数据库后的 `npm test`：11 项客户端测试、主仓库命令编排测试、Go 服务端测试。
- `TEST_DATABASE_URL=<本机测试实例> go test -race -count=1 ./apps/server/...`，包括旧开发账号改名、8 个并发登录、原应用与部署凭证/浏览器会话保留，以及新旧账号冲突拒绝。
- `RUN_BROWSER_TESTS=1 TEST_DATABASE_URL=<本机测试实例> go test -race -count=1 -run TestBrowserEndToEnd -v ./apps/server/internal/hosting`：真实 Chrome + CLI 设备授权、发布、来源隔离、保护、重试、重置、删除和退出。
- 无用户数据卷的临时 PostgreSQL 17.6 容器：新 cellapp 默认角色/库、数据库和角色改名往返、角色 OID 与表数据保留、SCRAM 密码登录、备份命令及临时管理员删除。容器已停止并自动删除。
- archify 对图表 JSON 和 HTML 的结构/布局检查；真实浏览器打开发布图并核对截图。
- 旧名称搜索逐项确认仅为兼容、迁移或历史用途；OpenSpec strict 变更校验、两仓库差异空白检查。
