- Website: `corepack pnpm run lint` and `corepack pnpm run build` passed. The production-preview browser test passed using the installed Chrome through `CHROME_PATH`. It fetched all four Markdown paths without authentication and checked the reciprocal language links. The Skill retains a local fallback when the website design guide cannot be fetched.

Their design trigger, framework choice, static hosting limits, deployment and recovery instructions were checked for parity. The runbook links to the guide in its own language.

- Release state: all edits are in the local task branches and remain uncommitted and unpushed. The website was built and tested locally but has not been uploaded to Cloudflare Pages. The Skill has not been published as an npm package.
