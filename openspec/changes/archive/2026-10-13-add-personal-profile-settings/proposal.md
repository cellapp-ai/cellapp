# Proposal

## Why

控制台目前只显示截断的账户 ID，用户没有独立页面查看账户信息或设置显示名称。需要一个稳定的资料入口，让用户确认当前账户并管理其显示名称，同时保持登录身份和应用地址不变。

## What Changes

- 增加受登录保护的 `/profile` 页面，展示完整账户 ID、当前登录模式，并允许设置或清除显示名称。
- 增加浏览器专用个人资料读取和更新接口，仅作用于当前会话所属账户。
- 对既有账户增加可空意义的显示名称字段，空字符串表示未设置；保持账户 ID、应用地址和登录身份不变。

## Capabilities

### Modified Capabilities

- `web-control-plane`: 当前所有者可查看和更新个人资料，深链和失败恢复与现有管理页面一致。

## Impact

- `apps/web` 页面、导航、浏览器验收；Go 控制 API 与控制库增量迁移；`docs/web-api.md` 和前端现状说明。
- 不更改公开 CLI、应用访客身份、命名空间或部署协议。迁移使用版本 006，避免与进行中的登录方式变更占用的版本 005 冲突。
