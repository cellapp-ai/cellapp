# Design

## Context

现有 `/api/console/session` 只返回 `ownerId` 和 `authMode`。`owners` 没有资料字段，控制台路由为显式白名单。另一个独立开发工作区正在实现多种登录方式及版本 005 身份表，本变更避免修改其身份映射。

## Decisions

- 增加 `owners.display_name`，默认 `''`，保存时要求首尾无空白、无控制字符，最多 80 个 Unicode 字符。版本 006 迁移独立于版本 005；迁移执行器按版本逐项记录和校验，因此两个增量均可在合并后执行。
- 使用 `GET` 和 `PUT /api/console/profile`。读取、更新都从 HttpOnly 浏览器会话解析账户；`PUT` 继承同源 Origin 与 JSON 大小限制，并返回保存后的值。保持既有 session 响应兼容。
- 页面将显示名称作为唯一可编辑字段。账户 ID 与登录模式只读，更新名称不改变应用地址或身份。加载、错误、成功、结果不确定、重新读取和会话过期沿用现有页面模式。
- `/profile` 纳入页面白名单与安全登录返回路径，导航提供当前页标记。移动布局、键盘与状态播报沿用控制台规范。

## Risks and recovery

- 更新响应丢失时，页面不自动重复提交；用户可刷新资料确认最终值。
- 身份方式变更分支合并时需调整登录模式的展示文字和前端 session 校验，保留本变更的资料接口与字段。
