# Cellapp 协作指引

本文件适用于整个仓库。项目的持续规范维护在 `docs/standards/`；这里提供阅读入口，不重复定义规则。

## 规范入口

| 文档 | 何时阅读 | 内容 |
| --- | --- | --- |
| [项目规范](docs/standards/project.md) | 开始任务、确认范围、构建、验证和交付前 | 项目边界、目录职责、静态交付、内容维护与验收 |
| [代码规范](docs/standards/code.md) | 编写或评审源码、脚本、样式和配置时 | 类型、组件、静态渲染、链接、样式与错误处理 |
| [设计规范](docs/standards/design.md) | 新增页面、调整布局、交互或品牌资产时 | 品牌、颜色、字体、布局、响应式与可访问性 |

规范的状态定义和维护方式见 [规范总览](docs/standards/README.md)。按任务涉及的领域阅读对应全文及验收清单；区分现状、必须要求、建议和待改进项，不把文档描述当成已经实现或验证的证明。

修改约定时更新对应的 `docs/standards/` 文档；移动或重命名文档时同步本文件的链接。
